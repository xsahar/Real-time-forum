File Responsibilities:
main.js: Entry point that initializes the app and sets up event listeners
app.js: Core application class that manages routing and components
users.js: Handles authentication (login/register) forms and logic
events.js: Global event handling for buttons and forms
navigation.js: Handles URL/route changes
api.js: Makes HTTP requests to the backend
chat.js: Chat functionality
posts.js: Posts listing and interactions
websocket.js: Real-time WebSocket communication
